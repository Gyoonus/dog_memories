# 다섯 강아지의 추억

강아지를 골라 그 아이와의 추억이 있는 장소로 들어가는 3D 공간입니다.
사람은 보이지 않고, 사람 눈높이에서 강아지를 바라봅니다. 간식을 줄 때만 손이 나와요.

**▶ https://gyoonus.github.io/dog_memories/**

## 강아지와 장소

| 강아지 | 장소 | 상태 |
|---|---|---|
| 핑키 | 푸맘네 집 (이태원동, 크리스마스 저녁) | 열림 |
| 푸푸 | 남산 산책길 | 준비 중 |
| 알팡 | 쇼핑센터 | 준비 중 |
| 재롱 | 정하는 중 | 준비 중 |
| 담이 | 정하는 중 | 준비 중 |

## 핑키 (푸맘네 집)

- 🐾 앉아 · 🛋️ 엎드려 · 🫠 드러눕기 · 🦴 간식 먹기 · 👃 냄새 맡기
- 간식을 주면 바로 앉아서 먹고 "하나 더?" 하고 쳐다봐요
- 냄새 맡기는 선물 상자, 밥그릇, 식탁 밑 순서로 돌아요

## 조작

| | PC | 모바일 |
|---|---|---|
| 강아지 고르기 | ← → / 클릭 | 좌우로 밀기 / 탭 |
| 둘러보기 | 마우스 드래그 | 화면 드래그 |
| 뒤로 | Esc | ‹ 친구들 |

## 구조

빌드 없는 정적 사이트입니다. `index.html` · `style.css` · `main.js`, three.js r160은 `vendor/`에 들어 있어요.
로컬에서 보려면 `python3 -m http.server`로 띄우고 `http://localhost:8000`을 열면 됩니다.
